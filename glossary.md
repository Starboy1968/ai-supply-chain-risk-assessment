# Glossary

| Term | Plain-language meaning |
|---|---|
| AI agent | An AI system that can take actions (send email, update records) not just answer questions. |
| AI-BOM | AI bill of materials: a list of the models, data sources and software components inside an AI system. |
| CASB / secure web gateway | Security tools that see and control which cloud apps and websites staff use. |
| Concentration risk | Many critical processes depending on the same provider, so one failure hits them all. |
| Deepfake | AI-generated audio or video that imitates a real person. |
| DLP | Data loss prevention: tools and rules that detect or block sensitive data leaving the company. |
| DPA | Data processing agreement: the contract setting how a vendor may handle your data. |
| Fourth party | Your vendor's vendor - for example the model provider behind a SaaS AI feature. |
| Hallucination | A confident AI output that is false or unsupported. |
| KRI | Key risk indicator: a metric that warns a risk is rising before it turns into an incident. |
| Model drift | A model's accuracy declining because real-world conditions changed since it was trained. |
| Prompt injection | Hidden or crafted text that makes an AI system ignore its instructions. |
| Shadow AI | AI tools used for work without IT or security approval. |
| Data / model poisoning | Tampering with training data or model files so the model behaves badly or maliciously. |
| Inherent vs. residual risk | Risk before controls vs. risk remaining after controls. |
